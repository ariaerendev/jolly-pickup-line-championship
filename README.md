A single pickup line from a robot whose scheduler has developed opinions. The program writes it to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

The output path defaults to `./out/entry.txt` and follows `MAKEFUN_OUTPUT_DIR` when that variable is set.
